# Дашборд по продажам сети «Соседушка»

## Задача
Руководитель сети продуктовых магазинов «Соседушка» ставит задачу: 
- «Хочу понимать, что происходит с продажами. Где мы растём, а где проседаем? Какие магазины лучшие, а какие тянут вниз? Помогают ли вообще карты лояльности — тратят ли держатели карт больше? И что с сезонностью — когда у нас провалы?»

## Данные
- Источник: файл `Соседушка_данные.xlsx` — данные о продажах сети продуктовых магазинов за 2024–2025 гг.
- Объём: 80 тыс. продаж за 2 года.
- Структура:
  - Факты: `fact_sales`;
  - Справочники: `dim_products`, `dim_stores`, `dim_customers`, `dim_suppliers`.

## Что сделано
1. Данные обработаны в Power Query: изменён тип столбца `дата_время` в таблице `fact_sales` с десятичного числа на дату.
2. Создана таблица `dim_calendar`, связана и помечена как таблица дат.
3. Создан набор мер под вопросы заказчика:
    - базовые: Выручка, Количество чеков, Средний чек, Количество клиентов;
    - сравнения: Средний чек по карте, Средний чек без карты;
    - время: Продажи пр. год, YoY %.
4. Создана таблица `Переключатель` и меры: Значение, Название графика 1, Название графика 2 для динамического переключения метрик.
5. Добавлены визуализации:
    - срезы по регионам, категориям, дате, метрикам;
    - карточки: выручка, количество клиентов, чеков, средний чек, сравнение чека;
    - линия выручки по месяцам;
    - столбцы YoY %;
    - столбцы по магазинам и категориям;
    - два столбца рядом: средний чек с картой vs без;
    - кнопки навигации.

## Выводы
1. Темпы роста в первой половине года были сильными (в апреле — пик +18%), но во втором полугодии они резко замедлились и к концу года скатились до 4%.
2. Лучшие магазины по выручке и среднему чеку — гипермаркеты, Москва и МО. Худшие — Нижегородская обл.
3. Карты лояльности не работают. Средний чек по карте ниже среднего чека без карты. К концу 2025 года разница увеличилась.
4. Январь даёт пик продаж за счёт праздников, основной вклад — рыба и морепродукты, алкоголь. В феврале идёт резкий постновогодний спад. Март стал рекордным месяцем по выручке, это связано с восстановлением после "провала" в феврале и праздником "8 Марта" (увеличение продаж сладостей). Виден "летний" всплеск в июле и августе (увеличение продаж напитков).
